# Push notification

This project integrates Firebase Cloud Messaging (FCM) into a React Native application to enable push notifications.

## Clone the project 
```bash
git clone https://github.com/Marc985/push_notification.git
cd push_notification

```

## Install dependencies
```bash
npm install
```

## Run application
Make sure you have an emulator running or a physical device connected.  

```bash
npm run android

```
